# Handoff — PTU Combat Electrodash Stuck 23

Electrodash's February 2016 bonus is now complete for the controlled Pokémon: a small manual **Stuck** state can be recorded in Combat, and a Pokémon with resolved Electrodash can remove it as a Shift Action. This does not spend a Scene use because the PDF labels it a Bonus, not the Ability activation.

Electrodash's existing `Scene x2 – Swift Action` still spends through the shared ledger to make Sprint a Free Action. Stuck has no opponent or map semantics; it is deliberately a controlled-state marker only. Windows and Android share the patcher and verifier. No `.ptucp`, merge, or release is changed.
