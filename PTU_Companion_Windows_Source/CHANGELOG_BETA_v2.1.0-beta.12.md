# PTU Companion Beta v2.1.0-beta.13

## Trainer Abilities

- Added a dedicated **Abilities** tab to the Trainer Sheet.
- Trainer Abilities resolved from Features, Edges and supported deterministic grants are listed automatically.
- Each Ability shows its granting source and its resolved rules text when available.
- Removing the Feature/Edge/source removes the automatically granted Ability through the existing Trainer Rules Engine.
- No campaign schema migration is required; this release exposes data already resolved by the engine.
