# PTU Companion Beta v2.1.0-beta.18

## Visual & navigation polish

- Pokédex & Rules now renders Pokémon portraits and item/definition artwork whenever the active definition exposes an image.
- Pokémon Progression · Stats adds an **Adjusted Base** column (Nature-adjusted/base-resolved value) next to existing allocations, new points and final Stats.
- Pokémon Progression · Abilities is aligned into a stable grid and adds a Details action that opens the resolved Ability description.
- Pokémon Progression · Moves separates the selection checkbox from the Move name; clicking the Move name opens its full resolved rule description.
- Roster and Storage selections now expose **Open in Creatures** for direct navigation to the selected Pokémon sheet.
- Shared responsive styles were added for the richer Rules Library and progression tables.

## Platforms

The same interaction model is mirrored in Android beta.19.
