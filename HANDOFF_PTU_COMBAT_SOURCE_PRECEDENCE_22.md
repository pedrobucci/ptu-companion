# Handoff — PTU Combat source resolution UX 22

This small follow-up makes the already-active source resolver inspectable in Combat. The new **Ruleset Source Resolution** panel shows the supplied order and the winning definitions for the controlled Pokémon's Quick Curl, Electrodash, Vicious, and Hone Claws where known.

The panel is read-only and reuses the same resolver used by the ability paths; it does not parse PDFs, alter action resources, or create a competing ruleset model. Windows and Android share the generated code. Draft PR #11 remains open; no `.ptucp`, merge, or release is changed.
