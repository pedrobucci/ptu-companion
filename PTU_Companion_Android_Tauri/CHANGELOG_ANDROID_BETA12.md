# PTU Companion Android v2.2.0-beta.14

## Trainer Abilities

- Added the **Abilities** tab to the mobile Trainer Sheet.
- Abilities resolved from Trainer Features, Edges and other supported grants now appear with provenance and rules text.
- The tab is horizontally scrollable with the other Trainer tabs on Android.
- No save migration is required.
- Android `versionCode` is now `2002014`.
