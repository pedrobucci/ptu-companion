# PTU Companion Android v2.2.0-beta.14

## Imported custom weapons

- Preserves `raw.mechanics` from imported Item definitions.
- Imported two-handed weapons now trigger the same Main Hand + reserved Off Hand flow as built-in weapons.
- Adept/Master Weapon Moves use the Trainer weapon qualification resolver and therefore honor Feature/Class skill substitutions such as Apparition.
- Imported weapon `compiled_effects` are active only while the item is equipped, supporting special Moves and Abilities.
- versionCode: `2002014`.
