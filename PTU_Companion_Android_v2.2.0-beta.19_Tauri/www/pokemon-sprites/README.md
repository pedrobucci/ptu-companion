# Android offline Pokémon sprites

1,090 compact PNGs (1,152,301 bytes) cover 1,093 exact PTU species IDs. They are bundled with the APK, not downloaded at runtime. Pack `portrait_data_url` takes precedence. Numeric filenames use PokeAPI Pokémon/form IDs, not national dex numbers for regional forms.

Sources, pinned for reproducibility:
- Sprites: https://github.com/PokeAPI/sprites/tree/6e3e7c43e86db0e1b2277795cfee41b11e8df2a4/sprites/pokemon
- Pokémon/form and species registry: https://github.com/PokeAPI/pokeapi/tree/5c776e225f2150862e021062d7f304c8958368cc/data/v2/csv
- Upstream sprite documentation and credits: https://github.com/PokeAPI/sprites/blob/6e3e7c43e86db0e1b2277795cfee41b11e8df2a4/README.md

Pokémon names and artwork belong to their respective owners (Nintendo, Game Freak, Creatures and credited sprite contributors). Bundling does not relicense the artwork. These files come from the default front-facing PokeAPI collection.

`manifest.json` records each PTU ID, upstream identifier, filename and SHA-256. `../pokemon-sprites.js` is the synchronous runtime lookup generated by `scripts/prepare-pokemon-sprites.mjs`. Explicit aliases cover regional and named forms; base species use the upstream default form. No fuzzy name matching is performed at runtime.

Twelve IDs have no mapping: `browt`, `chickute`, `gecqua`, `heafinha`, `needlene`, `pombon`, `terroster`, `panthore`, `panzeus`, `clefable-w`, `clefable-k`, `rotom-appliance-forms`. The four homebrew species already have pack portraits. The seven other names have no matching sprite in the pinned registry. The aggregate Rotom entry has no single correct appliance sprite; specific Rotom forms are mapped separately. These entries use pack portraits when present, otherwise the bundled default.svg.

Regenerate with `node scripts/prepare-pokemon-sprites.mjs`. No network or regeneration is needed to build or test the committed bundle.
