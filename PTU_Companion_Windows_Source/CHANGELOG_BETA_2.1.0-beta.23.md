# PTU Companion Windows 2.1.0-beta.23

- Adds the 48 Mega Forms from the supplied Pokédex catalog, with matching local form artwork and species-compatible Mega Stone entries.
- Applies a form's granted Ability while that form is active and restores the Pokémon's native Ability when it ends.
- Fixes Windows runtime packaging for the Forms modules and improves the active-form artwork and combat-card layout.
