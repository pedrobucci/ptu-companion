# PTU Companion — Functional Prototype v2.0.1

## Run

Requires Node.js 22+.

1. Extract the ZIP.
2. Optional: run `VERIFY_V20.bat`.
3. Run `RUN_FUNCTIONAL_PREVIEW.bat`.
4. Open `http://127.0.0.1:4173`.

No npm install is required for the functional preview.

## v2.0 focus

- Background Skills are mechanical base ranks.
- repeatable Trainer Edges/Features can store independent choices;
- selected choices appear directly on Feature/Edge cards;
- Combat tab legacy-equipment crash is fixed;
- Shop includes a ₽6000 Fine Two-Handed Sword test item;
- Trainer equipment can be equipped/unequipped from the Backpack;
- two-handed weapons reserve Main Hand + Off-Hand;
- Fine Weapon Moves unlock from qualifying Skill rank;
- Large Melee Weapon modifiers affect AC/DB;
- Apparition can qualify Melee Weapon Moves using Occult Education or Intimidate instead of Combat;
- Combat Move cards show weapon/qualification provenance.

The mature Pokémon vertical slice and v1.9 Trainer progression remain available.
