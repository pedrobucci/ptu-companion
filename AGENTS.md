# Project guidelines

Read `GITHUB_PUBLISHING_CHECKLIST.md` before building, releasing or cleaning generated artifacts. Its **Disk usage and local artifact retention** policy applies to local work and automations: measure free space, reuse the current toolchain, clean only identified disposable PTU artifacts, and notify Pedro when storage requires intervention.

Preserve local changes, campaign data and signing identities. Source history in Git does not back up ignored files, private keys or Docker volumes. Merge and publication continue to require the owner's approval.
