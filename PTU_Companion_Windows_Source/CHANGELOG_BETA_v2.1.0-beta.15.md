# PTU Companion Beta v2.1.0-beta.15

## Weapons v2

- Added generic imported-weapon support for Arcane, Living Weapon, alchemy, and legendary weapon mechanics.
- Arcane Weapon qualification uses Occult Education; imported Arcane Weapon Moves use Adept/Master tiers from PTU 1.05 Editation.
- Resolved weapons expose Physical/Special attack class, minimum range, shield metadata and contextual weapon rules.
- Imported weapons can contribute static Evasion/Damage Reduction while equipped.
- Preserves normal Feature-based alternate qualification for ordinary weapons (for example Apparition).
- Adds verifier for the 47-weapon + 1 supporting Move `campaign-homebrew-custom-weapons-2.0.0.ptucp` pack.
