# QA v2.0.1

Regression scenario reproduced from the v2.0 startup failure:

1. Persist a Trainer with `equipment: null` (valid legacy SQLite state).
2. Persist `ui.screen = trainer` and `ui.trainerTab = combat`.
3. Load the frontend.
4. Confirm migration expands the equipment object into empty slots.
5. Confirm Combat renders all empty slots without a JavaScript exception.
6. Confirm the normal application shell is inserted into `#app`.

The previous expression treated `null` as an object because JavaScript evaluates `typeof null === "object"`. It then attempted `null.name`, aborting `render()` before the shell was inserted.
